注意：API Key 安全

危險做法

const KEY = "gsk_abc123..."

Key 寫在程式碼裡
任何能看到程式碼的人
都能拿走你的 Key

正確做法

PropertiesService .getScriptProperties() .getProperty('GROQ_KEY')

Key 存在 Script Properties
程式碼裡只有取用邏輯

核心原則

密碼不能寫在程式碼裡 — 這個概念到 Stage 2 會變成 .env / Secrets
