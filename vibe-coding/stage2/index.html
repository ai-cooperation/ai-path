Stage 2 — 串 AI
跨越第二跳：從「用現成工具」到「讓 AI 幫你串流程」
M2-1 GitHub 平台熟悉

把 Stage 1 做的網頁，搬上全世界都看得到的地方
— 你的作品有了公開網址和版本紀錄

你會學到：GitHub 帳號申請與基本操作、檔案上傳並部署 GitHub Pages、Commit 版本控制概念、Public 與 Private 的判斷、跟 AI 一起的 4 步除錯儀式

帶走：1 個上線的 GitHub Pages 網頁（你的 username.github.io 網址）+ 累積的 commit 紀錄

GitHub Pages Commit 版本控制 Public / Private 4 步除錯儀式
M2-2 IDE 工具登場

第一次進到 IDE 開發環境
— 讓 AI 幫你改網頁、讀 PDF 整理重點、再產出一份簡報

你會學到：認識 IDE 介面三大區塊、AI 編程三大工具的差異、用 AI 改 HTML / 讀 PDF / 產簡報、信任資料夾與下清楚指令的訣竅、實際操作一輪 AI IDE 工作流

帶走：改過的網頁 + 一份 PDF 整理出的重點文件 + 一份自動生成的簡報

IDE 開發環境 AI 編程工具對比 PDF 整理 簡報生成
M2-3 IDE 接 GitHub 直接部署

把 M2-2 做的作品，從 IDE 一路 push 到網路上
— 不再手動上傳，一句話就完成上線

你會學到：SSH 金鑰與 Token 的認證差異、IDE 接上 GitHub 的完整流程、一句話就 commit + push、做多頁網站的 prompt 模板、從零開新專案部署上線

帶走：升級版多頁網站 + 一個全新的 repo 和新網址 + 累積的 commit 紀錄

SSH Key / Token IDE 接 GitHub 一句話 commit + push 多頁網站
M2-4 申請 API + 串接應用場景

從串一個 API、到真實應用場景、再到體驗 agent 模式
— 做出你的 Stage 2 期末成品

你會學到：認識三大免費 AI API 平台、了解 API 額度與 RPM 限制、API Key 安全流程（.env / .gitignore）、實作 AI 應用場景、第一次體驗 Agent 模式

帶走：一個會議摘要器（基礎版 → 含歷史紀錄的升級版）+ 一個串 API 的應用場景工具

免費 AI API API Key 安全 .env / .gitignore Agent 模式
