R4 ・ 把同一段 Prompt 拿去別的 AI 試試

```

```

這份 Instructions 應該包含以下所有部分,請逐一檢查不要漏:
- 角色定位(你是誰)
- 任務描述(你要做什麼)
- 輸出格式規範(回答長什麼樣)
- 語氣與風格要求
- 特殊情況處理規則(遇到 XX 怎麼辦)
